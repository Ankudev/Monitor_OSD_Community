# Historia zmian

## 0.1.1-alpha

1. Poprawiono typy i stany zdarzeń demo oraz objaśnienia dopasowania. Planowane przykłady są widoczne we właściwych filtrach; stare wpisy historii pozostają niezmienne.
2. Oznaczenie symulacji jest dostarczane razem ze stroną, także bez odpowiedzi API profilu. Zegary i opisy źródeł w panelu oraz SNUT zachowują tryb demo.
3. Dokument OpenAPI nie jest filtrowany jak dane katalogu. Oznaczenie demo korzysta z rozszerzeń specyfikacji.
4. Aplikacja automatycznie rozpoznaje pulpit SNUT dołączony do paczki. Pakowanie odmawia nadpisania istniejącego archiwum i pozwala wskazać osobne ścieżki wejściowe oraz wynikowe.
5. Poprawiono adres dokumentacji, opisy uprawnień i prywatnych pól, nazwy stron, etykiety ulubionych oraz kontrast informacji o źródłach.

## 0.1.0-alpha

Pierwsze wydanie Community: odrębna historia projektu, mapa i katalog 16 miejscowości, syntetyczne zdarzenia pięciu adapterów, historia, eksporty i pulpit SNUT. Publiczne demo umożliwia odczyt; operacje administratora, geokodowanie i wysyłanie powiadomień są wyłączone.

Własne instalacje mają osobne katalogi danych, uwierzytelnianie i politykę publikacji pól. Rzeczywiste źródła i pełne słowniki wymagają konfiguracji oraz własnego odbioru. Punkt orientacyjny miejscowości nie jest pomiarem ani potwierdzonym punktem zasilania.
