# Zgłaszanie podatności

Nie publikuj działających kluczy, danych użytkowników ani szczegółów umożliwiających wykorzystanie podatności w publicznym zgłoszeniu. Jeżeli w zakładce Security dostępne jest „Report a vulnerability”, użyj prywatnego zgłoszenia. W przeciwnym razie otwórz zgłoszenie zawierające wyłącznie prośbę o prywatny kanał kontaktu, bez szczegółów podatności.

Wersja alpha nie ma gwarantowanego czasu reakcji ani wsparcia starszych wydań. Publiczne demo służy do odczytu. Własne instalacje wymagają HTTPS, osobnych danych uwierzytelniających i aktualizacji zależności.
