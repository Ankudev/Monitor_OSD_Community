Monitor OSD Polska API v1

Publiczne API tylko do odczytu. Nie wymaga konta, tokenu ani klucza. Ma otwarty CORS dla dowolnej domeny. Odczyt API nie uruchamia dodatkowego pobierania danych od operatorów.

GET /api/v1/summary

Liczniki, stan świeżości i identyfikator migawki.

GET /api/v1/sources

Stan odczytów PGE, TAURON, ENERGA, ENEA i Stoen.

GET /api/v1/locations

Wszystkie monitorowane lokalizacje w jednej odpowiedzi. Odpowiedź zawiera pełne dane zapisane dla obiektów, TERYT, GPS, audyt lokalizacji i liczniki zdarzeń.

fetch('https://osd-demo.bieda.it/api/v1/locations').then(r => r.json()).then(console.log)

GET /api/v1/localities

Unikalne miejscowości pogrupowane według identyfikatora SIMC wraz z listą obiektów.

GET /api/v1/map

Jedna spójna migawka używana przez główny panel i SNUT: lokalizacje, zdarzenia, źródła, aktualność danych i liczniki.

GET /api/v1/objects

Obiekty. Parametry: q, view, fields, limit, offset.

GET /api/v1/events

Zdarzenia. Filtry: object_id, source, type, time_phase, from, to.

fetch('/api/v1/events?source=pge&limit=10').then(r => r.json()).then(console.log)

GET /api/v1/display/{object_id}

Niewielka odpowiedź JSON dla ESP32 i prostych wyświetlaczy. Brak zdarzeń nie jest potwierdzeniem zasilania. Zawsze sprawdź data_status.

GET /api/v1/history

Trwała historia zmian SQLite. Domyślnie 50, maksymalnie 200 wpisów na stronę. Filtry: source, object_id, from i to (obie daty ze strefą, z uwzględnieniem początku przedziału i bez uwzględnienia jego końca). Pobieraj kolejne strony wskazane w polu next aż do otrzymania wartości null. Po HTTP 409 zacznij od pierwszej strony.

history_id to stały UUID. before i after pokazują zmianę; snapshot oznacza zastaną obserwację. time_phase_at_recording dotyczy chwili zapisu. complete=false nie oznacza błędu: utraconej przeszłości nie odzyskamy. Archiwum zachowuje usunięte obiekty i wyłączone źródła.

Eksporty JSON/CSV pokazują do 200 ostatnich wpisów o zakończeniu publikacji lub dopasowania komunikatu, z jawnym zakresem i ograniczeniem. Całe archiwum jest dostępne przez kolejne strony historii lub CLI history-export z kopii bazy. Odczyty są publiczne i nie wywołują skanu operatorów.

Buforowanie i CORS

Każda odpowiedź ma ETag. Wyślij go jako If-None-Match, a przy braku zmian serwer zwróci 304 bez treści. API dopuszcza odczyt z dowolnej strony przez CORS.

Geoportal: zapisane porównanie lokalizacji

GET /api/v1/objects/{object_id}/location-review odczytuje zapisany wynik bez wysyłania zapytań do GUGiK. Nie wymaga tokena, obsługuje CORS i ETag. Pola current/expired opisują aktualność. Status consistent oznacza zgodność danych rejestru, nie potwierdzenie adresu obiektu ani zasilania.

POST /api/location/check z JSON {"object_id":"ID"} uruchamia limitowane porównanie albo korzysta z pamięci podręcznej. Także bez klucza. Nie zmienia obiektu. Błędy: 400 błędne dane, 404 nieznany obiekt, 409 zmiana podczas odczytu, 429 przerwa wymagana przez dostawcę, 503 problem lub wyłączenie funkcji.

Zasilanie rezerwowe obiektu

Przy dodawaniu i edycji zapisujemy rodzaj agregatu i dodatkowego toru zasilania oraz uwagi, np. „Sprawdzić paliwo” lub „Agregat uruchamiamy na miejscu”. Agregat i dodatkowy tor zasilania mogą występować jednocześnie. SZR oznacza samoczynne załączanie rezerwy.

Informacja jest widoczna na liście obiektów, w oknie opisu punktu na mapie i przy komunikatach. „Nie uzupełniono” nie oznacza braku agregatu. To opis wyposażenia podany przez użytkownika, bez pomiaru paliwa, sterowania lub potwierdzenia działania. Zmiana informacji nie zmienia GPS, adresu, audytu ani dopasowań.

Publiczne obiekty, lokalizacje i mapa mają power_supply z polami generator, secondary_feed i notes. Kody: unknown (nie uzupełniono), none (brak), manual (obsługa ręczna), szr (układ SZR). Uwagi do 1000 znaków są dostępne w pełnym widoku; compact pomija notes. PATCH zmienia tylko podane podpola. Historia i treść powiadomień pozostają bez zmian.

{"power_supply":{"generator":"szr","secondary_feed":"manual","notes":"Sprawdzić paliwo"}}

Ten JSON można wysłać metodą PATCH do /api/admin/objects/ID_OBIEKTU. Pobierz ID z publicznego katalogu. Zmiana pola generator nie usuwa dodatkowego toru zasilania ani uwag.

„Pokaż punkty i obszary operatorów” podaje liczbę narysowanych elementów albo informację o braku geometrii. Przewiń do mapy i przybliż wybraną okolicę, aby zobaczyć małe punkty.
